# 🦁 Canopy - Animal Biodiversity

Canopy is a simple, lightweight web platform focused only on **animals** of the rainforest. The entire project is built using **only HTML** for fast, accessible information.

### Objective
To create a digital canopy that documents and showcases rare and endangered animal species found in tropical forests.

### Features
- 🐅 Animal Profiles: Information on mammals, birds, reptiles, and amphibians
- 📍 Habitat Mapping: Shows where species live
- ⚠️ Endangered Alert: Highlights critically endangered animals
- 🎧 Sound Gallery: Animal calls (using HTML audio tag)
- 📖 Pure HTML: No CSS framework, no JavaScript - Only clean HTML structure

### Tech Stack
- HTML5 Only
